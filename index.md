# Constructing Event-Based Datasets of Geophysical Phenomena from Gridded Products: An Application to Antarctic Atmospheric Rivers

Welcome! This is the companion site for the paper *Constructing Event-Based Datasets of Geophysical Phenomena from Gridded Products: An Application to Antarctic Atmospheric Rivers*. On this site, you can find the Jupyter Notebooks used in the project, showing analyses, figures, statistics, and the code to produce them, all in a web-friendly HTML format. The notebooks here are lightly narrated and commented and are meant to be interpreted with the more detailed explanations and context provided in the full paper.

The website is organized in the following way:

+ Catalog Construction: details on the two-stage clustering procedure to create the AR catalog
+ Dataset Construction: cloud-friendly workflows to populate the AR catalog with quantities of each AR (turning the *catalog* into a *dataset*)
+ Dataset Explorations: some first-order results on Antarctic ARs that can be garnered with the resulting dataset
+ Quality Assurance: notebooks showcasing the various ways we've assessed the quality of our constructed catalog, including sensitivity analyses, external comparisons, and behavior all potential users should be aware of

If you would like to clone this project and use the notebooks yourself, see the GitHub README for details.
